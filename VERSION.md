# Version

## Current Planned Release

- Target release: `0.0.0-pre-alpha.1`
- Lifecycle phase: Pre-Alpha
- Release vehicle: `pre-alpha-1`

## Release Narrative

This pre-alpha milestone establishes the governed repository skeleton, local-first Docker Compose architecture, persistent PostgreSQL contract, and the validated Ollama mode-selection subset as a bounded learning artifact.

`pre-alpha-1` is the release cutoff for the macOS ARM64 implementation that includes the Ollama learning subset. It is not the intended long-term product baseline for `NLSW000003`.

`pre-alpha-2` is planned to remove the AI-related components, preserve a full dockerized OpenProject application, and re-establish the lean baseline before Alpha hardening begins.
