## Release Narrative

This pre-alpha milestone establishes the lean OpenProject-only release baseline after the discontinued Ollama and AI runtime subset was removed from active product scope.

`0.0.0-pre-alpha-1` remains the historical learning-artifact release that preserved the validated Ollama subset on macOS ARM64.

`0.0.0-pre-alpha-2` is the release that re-establishes the lean dockerized OpenProject baseline, preserves persistent PostgreSQL-backed operation, and limits validated release claims to the local macOS ARM64 footprint before Alpha hardening begins.
